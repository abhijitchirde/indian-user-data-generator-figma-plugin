## Stop wasting time manually creating fake Indian user data for your designs

**Indian User Data Generator** is the ultimate tool for designers and developers working on products for the Indian market. Generate realistic, culturally accurate Indian user data in seconds—from names and addresses to government IDs, business numbers, and payment details. Whether you're designing forms, dashboards, user profiles, or testing data tables, this plugin eliminates the tedious task of manually creating sample data and ensures your designs reflect authentic Indian user information.

## Universal Compatibility

This plugin works seamlessly across all Figma applications:

- **Figma Design** - Perfect for UI/UX design work
- **Figma Slides** - Great for presentations with sample data
- **FigJam** - Ideal for user personas and research documentation
- **Figma Buzz** - Works great for collaborative sessions (we recommend using "Open in a modal" via the icon button in the plugin panel for the best experience)

The plugin follows your Figma app's **light or dark theme** automatically, or you can pick Light or Dark yourself from the footer. It also **keeps the fonts and styling** of your target text layers (even when one layer mixes styles, like a bold first name), so generated data blends into your existing design.

## How to Use

### In Figma Design & Figma Slides

**Fill a whole card or profile at once:**

1. Rename the text layers in your card to what they hold, for example "Name", "Email", "Phone", "Address" or "PAN"
2. Select the card (or a list of cards, or just those text layers)
3. Click "Fill by layer names"—each card gets one matching person: the email and UPI ID use the person's name, and the address matches their city, state and PIN code

**Generate data in text layers:**

1. Select one or more text layers on your canvas
2. Choose the data type you want from the "Add to text layers" tab
3. Your selected text layers are instantly filled with realistic Indian data

**Use it without opening the plugin (quick actions):**

1. Select text layers (or a card)
2. Press Ctrl + / (Cmd + / on Mac), type "Indian User Data" and pick it
3. Type a data type, for example "email", "aadhaar" or "address", or choose "Fill by layer names" or "Regenerate selected data"

**Get new data without starting over:**

- Select layers, cards or tables the plugin filled before and click "Regenerate selected data", or use the "Regenerate data" button that appears in Figma's right panel when you select them

**Create user sets (tables, JSON and CSV):**

1. Open the "Create user sets" tab in the plugin
2. Select the fields you need using the checkboxes (basic fields are pre-selected)
3. Enter the number of users and choose the table shape: users as columns (one column per user) or users as rows (one row per user, better for many users)
4. Click "Add table to Figma" (up to 200 users; the table appears in the middle of your view, next to your existing designs, never on top of them, and Figma scrolls to it), or get the same users as a JSON or CSV download, or copy them as JSON or for spreadsheets (up to 10,000). "For spreadsheets" pastes straight into Google Sheets or Excel, one value per cell

### In FigJam

**For user personas and research:**

1. Create text layers for the information you need and name them (Name, Email, Address, etc.)
2. Select the text layers or the section holding them
3. Click "Fill by layer names", or pick data types one by one
4. Build comprehensive user personas with realistic Indian user data

**For data tables:**

- Use the table generation feature to create user data sets for research documentation and user journey mapping

### In Figma Buzz

**Recommended: Open in a modal**

- Click the icon button in the Figma Buzz plugin panel to open the plugin in a modal window for a better experience

**Generate data during collaborative sessions:**

1. Select text layers on your Buzz canvas
2. Generate individual data items or create full user data tables
3. Perfect for real-time collaboration on user research and design iterations

## Key Features

- **Fill by layer names** - Fill a whole card, profile or list of cards in one click, one matching person per card
- **Consistent users** - A user's email and UPI ID come from their name, and their address, city, state and PIN code belong together
- **Regenerate anytime** - Refresh data in place from the plugin or from Figma's right panel; cards and tables stay one person each
- **Culturally accurate** - All data follows Indian naming conventions, address formats, and ID structures
- **Preserves your design** - Keeps fonts and styling from your target text layers, including mixed styles; if a font is missing, Inter is used at the closest weight
- **Flexible user sets** - Any combination of fields, as a table on the canvas (long addresses wrap neatly; FigJam gets a native table), as JSON/CSV downloads, or copied for spreadsheets
- **Theme-aware interface** - Follows Figma's light or dark theme, or choose one yourself
- **Quick actions** - Fill or regenerate from Figma's command bar (Ctrl/Cmd + /) without opening the plugin
- **Remembers your setup** - The open tab, ticked fields, number of users, profession domains and theme are kept for next time

## Complete Data Generator Library

### Personal Information

- **First Name** - Common Indian first names
- **Last Name** - Common Indian surnames
- **Full Name** - Complete name combinations
- **Date of Birth** - Realistic birth dates (adults aged 18-80)

### Contact Details

- **Email** - Realistic email addresses with Indian name patterns
- **Mobile** - 10-digit Indian mobile numbers

### Location Data

- **Rural Address** - Complete rural addresses with village names
- **Urban Address** - Complete urban addresses with street names
- **City** - Real Indian cities
- **State** - All Indian states and union territories
- **City & State Pair** - Matching city-state combinations
- **Pin Code** - 6-digit PIN codes starting with the state's postal zone

### Professional Information

- **Professions** - Realistic job titles across multiple domains (Tech and IT, Engineering, Management, Healthcare, Finance, Science, Education, Art and media, Hospitality, Construction, Government, Volunteering, and more)

### Government IDs & Documents

- **Aadhar (UID)** - 12-digit Unique Identification numbers
- **PAN** - Permanent Account Number (Tax ID)
- **Voter ID** - Indian Voter Identification numbers
- **Passport** - Indian passport number format
- **Driving License (DL)** - State-specific driving license numbers

### Financial & Payment

- **UPI Address** - UPI payment addresses (name-based and mobile-based formats)

### Vehicle Registration

- **RC (Registration Certificate)** - Traditional vehicle registration numbers (state-specific)
- **RC BH Series** - Bharat Series vehicle registration numbers

### Business Identification Numbers

- **GSTIN** - Goods and Services Tax Identification Number
- **CIN** - Corporate Identity Number
- **DIN** - Director Identification Number
- **LLPIN** - Limited Liability Partnership Identification Number
- **PAN (Business)** - Business Permanent Account Number
- **TAN** - Tax Deduction and Collection Account Number
