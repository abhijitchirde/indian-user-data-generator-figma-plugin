Indian User Data Generator is the ultimate tool for designers and developers working on products for the Indian market. Generate realistic, culturally accurate Indian user data in seconds, where every user makes sense: the email matches the name, and the address matches the city, state and PIN code.

Works in Figma Design, FigJam, Figma Slides and Figma Buzz.

📖 How to Use

Fill a whole card at once:
1. Name your text layers "Name", "Email", "Phone", "Address", "PAN"…
2. Select the card (or several cards) and click "Fill by layer names"

Generate data in text layers:
1. Select one or more text layers on your canvas
2. Click the data type you want in the plugin panel

Generate user data sets:
1. Open the "Create user sets" tab in the plugin
2. Select the fields you need using the checkboxes (basic fields are pre-selected)
3. Enter the number of users and choose users as columns or rows
4. Click "Add table to Figma" to create a data table on your canvas, or download or copy the users as JSON or CSV

✨ Also
- Regenerate: select filled layers or tables and click "Regenerate data" in Figma's right panel for fresh data
- Quick actions: press Ctrl + / (Cmd + / on Mac), type "Indian User Data" and pick a data type, without opening the plugin

⚠️ Disclaimer
Everything here is made up locally for designs and testing. Names, IDs and addresses aren't real, and any match with a real person or business is a coincidence.
